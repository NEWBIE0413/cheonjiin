# 천지in — 앱스토어 문구

이름(30자): 천지in
부제(30자): 광고 없는 오픈소스 천지인 키보드
카테고리: 유틸리티 · 가격: 무료 · 연령: 4+

## 프로모션 텍스트 (170자)

가볍고 빠른 천지인 키보드. 광고도, 추적도, 구독도 없어요. 코드는 GitHub에 전부 공개돼 있어요.

## 설명

ㅣ ㆍ ㅡ 세 획이면 충분해요.
천지in은 군더더기 없는 천지인 키보드예요.

■ 가볍게
· 키를 누르는 순간 바로 입력돼요.
· 지울 때는 누른 순서를 거꾸로 되감아요. 가기 → 각 → 가
· 간격 키는 조합 중일 때 조합만 끝내고, 아니면 띄어써요.
· 글자 키나 간격 키를 좌우로 밀면 커서가 움직여요.
· 키를 꾹 누르면 같은 글자가 계속 들어가요. ㅋㅋㅋ, ㅠㅠㅠ
· 가로 화면에서는 두벌식 자판으로 바뀌어요.

■ 내 손에 맞게
· 지구본 키로 천지인·두벌식·English를 원하는 순서로 오가요.
· 연속 입력 빠르기, 진동 세기, 키 소리, 키 높이, 커서 감도를 앱에서 바꿀 수 있어요.

■ 조용하게
· 광고, 추적, 구독이 없어요.
· 네트워크 코드가 없어서 입력한 글자가 어디로도 나가지 않아요.
· '전체 접근 허용' 없이도 모든 기능이 동작해요. 전체 접근은 진동과 키 소리에만 쓰여요.

■ 투명하게
· 모든 코드가 GitHub에 MIT 라이선스로 공개돼 있어요.
  github.com/oesoll/cheonjiin

■ 시작하기
설정 › 천지in › 키보드에서 '천지in'을 켠 뒤, 입력창에서 지구본 키를 눌러 고르세요.

## 이번 버전 (1.0.1)

· 지구본 키: 천지인·두벌식·English를 원하는 순서로 오가요.
· 앱에서 설정: 언어 목록, 연속 입력, 진동 세기, 키 소리, 키 높이, 커서 감도
· 가로 화면 두벌식, 꾹 눌러 연속 입력(ㅋㅋㅋ), 글자 키를 밀어 커서 이동
· 키 소리 추가, 반응 속도 개선
· 메시지를 보낸 뒤 앞 글자가 다시 끼던 문제와, 선택된 글이 밀기로 지워지던 문제를 고쳤어요.

## 심사 메모

키보드 확장 앱입니다. 설정 › 일반 › 키보드 › 키보드 › 새로운 키보드 추가에서 '천지in'을 추가하면 동작합니다.
전체 접근 없이도 모든 입력 기능이 동작하며, 전체 접근은 진동과 키 소리에만 사용합니다. 네트워크를 사용하지 않습니다.
지구본 키를 탭하면 앱에서 설정한 언어(천지인·두벌식·English) 사이를 전환하고, 길게 누르면 다음 키보드로 전환됩니다. 앱 설정은 App Group 저장소로만 키보드에 전달됩니다.
