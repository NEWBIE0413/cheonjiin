# 천지in

광고 없는 오픈소스 천지인 키보드 (iOS)

ㅣ ㆍ ㅡ 세 획이면 충분해요. 천지in은 군더더기 없이 가볍게 만든 천지인 키보드예요.

- 광고, 추적, 구독이 없어요.
- 네트워크 코드가 없어요. 키보드는 입력한 글자를 어디로도 보내지 않아요.
- '전체 접근 허용' 없이도 모든 입력 기능이 동작해요. 전체 접근은 진동과 키 소리에만 쓰여요.

## 입력 방법

| | |
|---|---|
| 모음 | ㅣ ㆍ ㅡ 세 획을 이어 누릅니다. ㅣㆍ = ㅏ, ㆍㅣ = ㅓ, ㆍㅡ = ㅗ, ㅡㆍ = ㅜ, ㅡㆍㆍㅣ = ㅝ |
| 자음 | 같은 키를 이어 누르면 ㄱ → ㅋ → ㄲ |
| 간격 | 조합 중이면 조합만 끝내고(안녕: ㄴ, 간격, ㄴ), 아니면 띄어씁니다. 좌우로 끌면 커서 이동 |
| ⌫ | 누른 순서를 거꾸로 되감습니다. 가기 → 각 → 가. 길게 누르면 단어째 지웁니다 |
| .,?! | 연타로 . , ? ! 를 오갑니다 |
| 🌐 | 탭: 설정한 언어 순서대로(천지인·두벌식·English), 길게: 다음 키보드 |
| 123 | 숫자·기호 두 쪽(1/2, 2/2) |
| 길게 누르기 | 같은 글자를 계속 입력(ㅋㅋㅋ, ㅠㅠㅠ) |
| 밀기 | 글자 키나 간격 키를 좌우로 밀어 커서 이동 |

가로 화면에서는 한글이 두벌식으로 바뀝니다.

앱에서 바꿀 수 있는 것: 언어 목록과 순서, 가로 화면 두벌식, 길게 누르기(켜기·시작 시간·빠르기), 진동(켜기·세기), 키 소리, 키 높이(세로·가로), 밀어서 커서 이동(켜기·감도).

## 구조

- `Core/` — 천지인 조합 엔진(`CheonjiinEngine`). UIKit에 의존하지 않는 Swift 패키지로, `swift test`로 조합 규칙 전체를 검증합니다.
- `Keyboard/` — 키보드 확장. SwiftUI 없이 UIKit 뷰 하나가 터치를 직접 받아 그립니다.
- `App/` — 키보드를 켜는 방법을 안내하는 컨테이너 앱.

## 직접 빌드하기

필요한 것: Xcode 16 이상, [XcodeGen](https://github.com/yonaskolb/XcodeGen)

```sh
cp Config/Local.xcconfig.example Config/Local.xcconfig   # 자기 팀 ID와 번들 ID 접두사를 넣는다
xcodegen generate
open Cheonjiin.xcodeproj
```

조합 엔진 테스트:

```sh
cd Core && swift test
```

## 개인정보처리방침

천지in은 어떤 개인정보도 수집하거나 저장하거나 전송하지 않습니다.

- 키보드와 앱 모두 네트워크를 사용하지 않습니다.
- 입력한 글자는 기기 안에서 조합에만 쓰이고, 저장되거나 외부로 나가지 않습니다.
- 광고, 분석, 추적 도구를 포함하지 않습니다.
- '전체 접근 허용'은 진동·키 소리와, 앱에서 고른 설정을 키보드에 전하는 데만 쓰입니다. 꺼도 기본 설정으로 모든 입력 기능이 동작합니다.
- 설정은 기기 안의 App Group 저장소에만 저장됩니다.
